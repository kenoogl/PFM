# Repository Guidelines

## プロジェクト構成
このリポジトリは、三相分解の相場場シミュレーションと可視化用の小規模な C++ ワークスペースです。主要ファイルは以下です。

- `three_phase_decomp.cpp`: 主シミュレーション本体
- `three_phase_decomp_save.cpp`: 保存用の派生版
- `plot.cpp`: `.dat` 出力の可視化ローダ
- `bplot.cpp`: 指定時刻の BMP 書き出し
- `wingxa.h`, `wingxa.cpp`: 旧 `wingxa` 依存を置き換える互換実装

サンプル出力は `test1.dat` と `test2.dat` にあります。既存の画像例は `bmp1/` と `bmp2/` に `c_field_<step>.bmp` 形式で保存されています。

## ビルド・実行コマンド
この環境では `Makefile` を使います。

- `make`: `three_phase_decomp`、`plot`、`bplot` をまとめてビルド
- `make bplot && ./bplot`: `test1.dat` から BMP を生成
- `make clean`: 実行ファイルと作業ディレクトリ直下の `c_field_*.bmp` を削除

Windows 向けの旧手順として `vpp.bat` と `vppp.bat` も残していますが、通常は `make` を使ってください。

## コーディング規約
既存コードのスタイルを優先してください。

- `.cpp` のインデントは既存に合わせる
- マクロは `ND`、`INX`、`INY` のように大文字
- 既存のグローバル変数名 `c2h`、`c3h`、`time1` などはむやみに変更しない
- 出力ファイル名は `test*.dat`、`c_field_<step>.bmp` を維持する

大きな整理より、局所的で追いやすい修正を優先します。

## テスト方針
自動テストはありません。変更時は以下を最低限確認してください。

- 対象プログラムがビルドできること
- `./bplot` が正常終了し、BMP を生成できること
- 数値ロジック変更時は、既存の `test1.dat` や `bmp1/` `bmp2/` と傾向が大きく崩れていないこと

表示系はヘッドレス互換実装のため、確認は主に生成ファイルで行います。

## コミット・プルリクエスト
この作業ツリーでは Git 履歴を参照できないため、コミットメッセージは命令形で簡潔に書いてください。例: `Fix concentration clamp in time step loop`

プルリクエストには以下を含めてください。

- 変更内容の要約
- 影響を受けるファイル
- 実行した確認コマンド
- 出力が変わる場合は生成 BMP 例や差分の説明
- 必要なら対象 OS やビルド前提条件
